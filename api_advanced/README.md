# API Advanced

This project contains Python scripts that query the Reddit API recursively and parse results.

## Files

- `0-subs.py`: Return total subscribers for a subreddit (0 if invalid).
- `1-top_ten.py`: Print titles of first 10 hot posts for a subreddit.
- `2-recurse.py`: Recursively return all hot post titles for a subreddit.
- `3-count.py`: Recursively count and print sorted keyword occurrences in hot titles.

## Usage

```bash
python3 0-subs.py      # via 0-main.py
python3 1-top_ten.py   # via 1-main.py
python3 2-recurse.py   # via 2-main.py
python3 3-count.py     # via 3-main.py
```

## Run the local checker

```bash
python3 check_requirements.py
```
